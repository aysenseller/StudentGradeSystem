# Student Grade System

A Python-based student grade management system that runs in the terminal.

## Features

- Add students
- Show students
- Find students
- Edit students
- Delete students
- Add grades
- Calculate student averages
- Show statistics
- Save data as JSON
- Load data from JSON
- Input validation
- Automated tests with pytest

## Technologies

- Python
- JSON
- Pytest
- Git
- GitHub
